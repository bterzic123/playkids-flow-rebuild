# Growth Audit — PlayKids Learning

**Live:** https://bterzic123.github.io/playkids-flow-rebuild/

Five ranked ideas plus a clickable prototype of a PlayKids onboarding and paywall, rebuilt in PlayKids' own design. Today a new install opens straight on the paywall. The prototype adds four quick questions for the parent, a setup screen, a personalised paywall and a second chance when the paywall is closed.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Let parents set it up before the price | CR +10–20% |
| 02 | Make the paywall about their child | CR +15–20% |
| 03 | Show the saving, then the button | ARPU +10–15% |
| 04 | A second chance without a trial | ARPU +10–15% |
| 05 | Say 70 million, not “millions” | CR +5–10% |

Impact ranges are Adapty's expected effect from teardowns and A/B tests across subscription apps — not measured lift for PlayKids Learning.

**Grounding.** Every price, count and feature line comes from PlayKids' own Android paywall, Google Play listing and App Store listing. The photo and wordmark are taken from the paywall itself.

**Run locally**

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
